如何解決 PVE VM 開機後沒有網路

Aug 29, 2026
閱讀時間: 1 分鐘
English

喔好啦我覺得其實這有點標題黨，但如果你跟我一樣 PVE VM 開機後會遠端不到或許可以看看這篇文章

前情提要

故事大綱大概是我在不久前拿到了一台 PVE 機器，性能蠻好的，在這記憶體價格飛漲的年代還有 4T+128G 可用，當然要好好使用這台機器！

但電腦主人有用高貴的 UDM Pro Max 設 VLAN，跑在某個網段

問題

只要我 VM 通外網後我就會遠端不到，不是 VM 而是整台 PVE

解決方法

發現問題後我想到可能的原因

1 是 VM 的 DHCP 搶到 PVE 的 IP 導致遠端不進去

2 是我

原因一的解決方法

我開了一個 NAT 讓所有 VM 的流量都用 PVE 的 IP 出去，如下：

auto vmbr1
iface vmbr1 inet static
        address 192.168.100.1/24
        bridge-ports none
        bridge-stp off
        bridge-fd 0
        post-up echo 1 > /proc/sys/net/ipv4/ip_forward
        post-up iptables -t nat -A POSTROUTING -s '192.168.100.0/24' -o vmbr0 -j MASQUERADE
        post-down iptables -t nat -D POSTROUTING -s '192.168.100.0/24' -o vmbr0 -j MASQUERADE

本來想說這樣就不錯了，但不知道為啥 VM 網路最高只有 20M，想到後面每台都要手動設定 IP 還只有 20M，就想說肯定還有更佳解，於是我就繼續查問題

最後的真正問題

花了半個多月在 PVE 和 Google 上找資料找相似問題都找不到，我就開始想會不會是更上層的 UDM Pro Max 設定有誤，於是要了 UniFi OS 帳號來看

不看還好，一看嚇一跳

你老哥的怎麼把 Vlan Tag 設 Allow 都沒說 後來我就關掉這設定就圓滿結束ㄌ
