Stream

  • Number of Solvers：146/389
  • Author：Whale120

According to the code,

1

print(hexor(flag, getrandbits(256)))

That is, C = flag XOR (k ** 2)
Since XOR is reversible, we can use the beginning of FLAG, AIS3{, to work backwards.

AIS3{’s ASCII code is 41 49 53 33 7B
Convert it to bytes, and then see which segment, starting from the 25th byte from the end (because flag is about 25 bytes long), can be XORed with the characters AIS3{ to calculate the bytes corresponding to k**2.
For example:

1
2

c_byte[i] = flag_byte[i] XOR k_squared_byte[i]
=> k_squared_byte[i] = c_byte[i] XOR flag_byte[i]

This allows us to deduce the contents of k_squared over several bytes.
Then convert it to bytes and check if it matches the leading AIS3{

import math

# 已知的旗標前綴和後綴
prefix = b"AIS3{"
suffix = b"}"

with open("output.txt", "r") as f:
    lines = f.read().splitlines()
cipher_hex = lines[-1].strip()
cipher_int = int(cipher_hex, 16)

flag_found = None
key_int = None

for L in range(6, 50):
    if L < len(prefix) or L < len(suffix):
        continue  
    X = cipher_int & ((1 << (8 * L)) - 1)     
    H = cipher_int >> (8 * L)                
    # 計算可能的k值範圍
    lower_bound = H << (8 * L)
    upper_bound = (H << (8 * L)) + ((1 << (8 * L)) - 1)
    k_min = math.isqrt(lower_bound)    
    if k_min * k_min < lower_bound:
        k_min += 1
    k_max = math.isqrt(upper_bound) 
    if k_min > k_max:
        continue
    for k in range(k_min, k_max + 1):
        k_square = k * k
        if not (lower_bound <= k_square <= upper_bound):
            continue
        plaintext_int = cipher_int ^ k_square
        plaintext_bytes = plaintext_int.to_bytes(L, 'big')
        if plaintext_bytes.startswith(prefix) and plaintext_bytes.endswith(suffix):
            flag_found = plaintext_bytes
            key_int = k
            break
    if flag_found:
        break

print("FLAG:",flag_found.decode('utf-8', errors='ignore'))

Random_RSA

  • Number of Solvers：83/389
  • Author：hahabox0

The question mentions using LCG to generate p and q.

1

rng = lambda x: (a*x + b) % m

Then, run rng() from seed until it hits a prime number, which is used as p. Then, run rng() again from p, finding the next prime number and using it as q.
The question gives three consecutive LCG outputs, so we can infer a and b.

1
2
3

h0 = rng(seed)
h1 = rng(h0)
h2 = rng(h1)

According to the LCG formula,

  • h1 = a*h0+b mod m
  • h2 = a*h1+b mod m

Algebraic derivation yields

  • a = $\frac{h2-h1}{h1-h0}$ mod m
  • b = h1 - a*h0 mod m

m is a prime number, so we can perform a modular reciprocal.
LCG has a closed form, so let q = rng^t(p). Since n = pq, we get:
$a^t$$p^2$+b * $\frac{a^t-1}{a-1}$ p-n=0 mod m
We can solve for p and verify that n=p q
After solving for p and q, we can calculate the private key d and then use

1

m = pow(c, d, n)

to restore the plaintext

After testing, I discovered that the problem breaks the plaintext into 8-byte chunks.
Each plaintext chunk, $m_i$, is an 8-dimensional vector (8 numbers).
So, we can calculate the mod21 inverse matrix of A.
$m_0$ = $x^-1$ * $c_0$
$m_1$ = $x^-1$ * ($c_1$ - B * $m_0$)
Concatenate $m_0$ to $m_4$ and convert them into a string, and the flag will appear.

from pwn import *
import numpy as np, re

MOD = 251
HOST, PORT = "chals1.ais3.org", 18000

def nums(line: bytes):
    return np.fromiter(map(int, re.findall(rb"\d+", line)), int, 8)

def inv(mat):
    n = 8
    aug = np.hstack([mat.copy(), np.eye(8, dtype=int)])
    for i in range(n):
        j = next(k for k in range(i, n) if aug[k, i])
        aug[[i, j]] = aug[[j, i]]
        aug[i] = (aug[i] * pow(int(aug[i, i]), -1, MOD)) % MOD
        for k in range(n):
            if k != i:
                aug[k] = (aug[k] - aug[k, i] * aug[i]) % MOD
    return aug[:, n:]

io = remote(HOST, PORT)

flag_ct = np.array([nums(io.recvline_contains(b"[")) for _ in range(5)])

payload = b"".join(bytes([1 if i == j else 0 for i in range(8)]) + bytes(8) for j in range(8))
io.sendline(payload)
oracle = np.array([nums(io.recvline_contains(b"[")) for _ in range(16)])
io.close()

A = np.column_stack(oracle[0::2]) % MOD
B = np.column_stack(oracle[1::2]) % MOD
Ainv = inv(A)

pt, prev = [], None
for c in flag_ct:
    m = (Ainv @ (c if prev is None else (c - B @ prev))) % MOD
    pt.append(m); prev = m

print(bytes(int(x) for x in np.concatenate(pt)).split(b"\0")[0].decode())
